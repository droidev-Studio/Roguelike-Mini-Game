# 敌人安全出生与 Pages 发布修复

## 问题与修复

普通怪、弓手编队、木牛、精英、虎卫、守将、秦琪分身、召唤物和潮汐原先直接加入敌人列表，未检查世界边界及地形碰撞；换图也只修正玩家。出生在障碍内部时，每帧的小步移动不足以穿过障碍，导致敌人长期卡住。

`addEnemySafely` 统一所有生成入口，使用与移动一致的半径 `max(12, size × 0.62)`，检查完整圆形占地以及世界边界。优先保留合法原位置，其次环形搜索附近空位，最后有限网格搜索；找不到合法位置则拒绝生成，不能返回已知阻挡点。守将生成失败时撤销生成标记，允许后续重试。

判定复用现有圆形、椭圆、矩形和 collisionScope 规则，保留 playerOnly、减速区域及忽略地形的既有语义。切换静态地图后修正存活敌人的位置，保留对象及 HP；移动前检查被击退、旧存档或动态地形造成的内部重叠，先脱困再移动。

## 验证

- 修复前重放原始无校验插入：21 个有尺寸的 manifest 地图配置（包含别名），共 8,400 次普通怪/弓手生成，发现 77 次与适用于敌人的地形重叠，另存在越界出生。
- 相同范围修复后：8,400 次生成，碰撞重叠与越界均为 0。
- 32 项浏览器受控断言：三种形状、四种体型、移动脱困、全图阻塞拒绝生成、playerOnly/slow 语义、8 类生成入口、对象及 HP 保留、真实静态地图切换。
- 130 秒实时时长内，正常按键试玩约 128.9 秒游戏时间，27 个记录样本未发现敌人地形重叠，页面错误为 0。此结果不是完整五关通关或胜率证明。
- 语法、TypeScript、10 项战役规则、资源校验、P0 基础玩法和已有战役受控场景通过。

测试入口：`tools/terrain-spawn-regression.mjs --out=绝对报告目录`；修复前重放另加 `--baseline=1`。受控测试显式设置地图/实体，只用于功能回归。

## 发布

原 Pages 流程直接复制源码，遗漏 `SaveManager.js`，且编辑器的 `import.meta.glob` 需要 Vite 转换。`tools/build-pages.mjs` 先以相对 base 构建 Vite 模块和 CSS，再复制经典脚本、spec、资源和 vendor，排除资源归档。UI 皮肤动态地址以 HTML 根地址解析，避免 CSS 打包到 assets 后出现重复 assets/assets 路径。`release.json` 记录构建 commit、时间及关键文件 SHA-256。

`tools/pages-smoke.mjs` 可对本地静态产物或线上地址校验版本、文件哈希、真实开始/移动/暂停/继续、编辑器加载、刷怪和浏览器/HTTP 错误。现有 `main` 分支的 GitHub Pages 工作流负责部署。

本次发布包含本地此前已完成的战役循环、UI 和美术工作，保持当前主工程的资源引用一致；未将本地未跟踪的资源归档纳入提交。

# 线上地形验收与入口循环修复

## 本轮发现

线上入口归一化存在确定性重载循环：GitHub Pages 只添加美术参数，没有添加本地分支的功能参数，而退出条件要求两组参数同时存在。`location.replace` 因此反复导航到同一个 URL，导致 game.js 等脚本请求不断中止，页面无法启动。2026-10-29 上午的浏览器诊断已观察到 HTTP 200 文档重复导航与大量 ERR_ABORTED；此前 429 不能仅归因为平台偶发限流，请求循环可能是其诱因。

## 改动

- 入口为本地和 GitHub Pages 填入一致的默认功能参数，保留显式值、seed、其他参数和 hash。
- 通过 `history.replaceState` 原地更新地址，使后续脚本读取到正确开关，不重新请求页面；重复执行达到固定状态。
- 新增 5 项入口回归，覆盖生产域名、重复执行、手动参数、本地及其他域名。修复前存在断言失败，修复后全部通过。
- 发布指纹补入构建后的 index.html 与 UIBridge.js；浏览器验收记录主文档请求次数，反复导航时提前终止。
- 试玩审计只包装原始生成、换图修复方法并观察结果；不调整血量、时间、升级或敌人内容。受控生成/换图场景另行记录，不作为正常通关证据。

## 发布前验证

语法、类型、10 项战役规则、5 项入口规则、资源校验与 P0 基础玩法均通过。独立静态产物启动/移动/暂停/恢复/UI/生成检查通过，无页面或 HTTP 错误。地形受控回归 38 项通过：8,400 次生成零重叠/越界、8 类入口、三种形状及不同体型，并覆盖六个地图配置的保留敌人换图、HP 保留和移动性。

实际线上试玩结果将以本轮独立报告和后续回执为准；此段发布前检查不代表线上验收完成。
